# 10. Data-quality checks

**Question:** Can the numbers in the other nine queries be trusted? Each row is one check, and issues_found should be 0.

**Techniques:** UNION ALL to stack independent checks into one result, NOT EXISTS anti-joins to find rows with no match, and COUNT(*) minus COUNT( DISTINCT ...) to count duplicates.

**Notes:** The data generator plants two realistic problems on purpose, so this query has something to find: returning customers who registered again with the same email in different letter case, and cash jobs that were never entered as payments. Comparisons with NULL are never true, so check 4 skips missing timestamps; check 5 is the one that catches those.
